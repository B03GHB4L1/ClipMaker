VizorPlay

User manual

Version 1.0. How to turn match event data and footage into clips, analysis and annotated videos, entirely on your own computer.

Screenshots use a made-up demo match (Northbridge v Southport) with a synthetic test video, so no real footage or data is shown.

The workflow in one line

Intake (load a match and footage, align the clock) → Filter (find the moments) → Export a reel → optionally Annotate. Code lets you tag a match yourself while watching; Analyst and Tactical read the same data as charts.

Everything runs and is stored on your computer. Footage is used where it is and never copied. Nothing is uploaded, and the app sends no usage data.

1. Getting started

Install VizorPlay for your system from the download page (Windows installer, macOS disk image for Apple silicon or Intel, Linux package) and open it. The status at the top right reads Engine ready once the built-in engine has started. If it reads anything else, see Troubleshooting.

The layout

  • Tabs at the top: Intake, Code, Filter, Analyst, Tactical, Annotate. They work in that order, but you can move freely.
  • VizorPlay menu (the three dots): jumps between the same screens and shows the workspace.
  • New project (Intake, top right): starts a fresh project. Your previous project is saved first and is never overwritten.
  • Footer: the version (1.0), a theme switch (system, light or dark) and full screen.

What a project is

A project is one piece of work saved locally: its match data, footage reference, kick-off alignment, filters and export settings. Every project is independent. The top right of each screen shows Saved locally when your work is stored.

2. Match intake

Intake gets a match and its footage into the project. It has three parts: A Match source, B Match footage and Align the match.

A. Match source

Choose one of these:

  • Paste a link: a Scoresway or WhoScored match URL, then press the arrow button to fetch the events.
  • Import match CSV: pick an event file you already have.
  • Add a saved match: reuse a match you fetched before (see Matches in section 8).
  • Batch scrape: open it, paste one match URL per line, press Scrape batch.

Once loaded, the saved-match card shows the teams, score and event count. Browse event data opens a searchable table of every event, with a period filter and an Open full table link.

B. Match footage

Press Choose match footage and pick an MP4, MKV or MOV. The file stays where it is. If your recording is split into periods, open Separate period videos and choose a file for the second half, extra time 1, extra time 2 or penalties.

Align the match

Events are tied to the match clock, so VizorPlay needs to know where kick-off is in your video.

  1. Pick the period button (1H, 2H, ET1, ET2, PEN). Extra time and penalties are enabled with their checkboxes only when the match had them.
  2. Scrub the video to the whistle with the step buttons (−1m, −10s, −1s, −1f, play, +1f, +1s, +10s, +1m). The zoom buttons (Full, 10 min, 2 min) refine the timeline.
  3. Press Set kick-off here. The period marker appears and the time is shown.
  4. Repeat for each period, then press Confirm & continue. Reset marker undoes a marker.
Local history at the bottom of Intake lists your saved projects. Open one with its arrow, or delete it with the bin.

3. Code: tag a match yourself

Use Code when you have footage but no event feed, or when you want your own tags on top of the feed. Watch the video and press keys to mark what happens.

Codes, intervals and tags

  • Codes mark a moment at the playhead for the chosen team: Goal, Shot on target, Shot off target, Save, Corner, Foul, Card, Offside, Ball won, Ball lost, Key moment. Each has a single-letter key shown on its button.
  • Intervals (Possession, Build-up, Pressing, Transition) have a start and an end: press the key once to start, again to stop. A running timer shows on the button.
  • Tags add detail with Shift plus a letter: Left, Centre, Right, Successful, Unsuccessful, Header, Set piece, Counter-attack, Big chance.
  • Team: H and A (or the Home and Away buttons) choose which team a code belongs to.

Pitch location, teams and squads

  • Pitch location: click the small pitch to say where the chosen event happened. Drag to also mark where it ended, for example a pass target.
  • Teams and keys: rename the home and away teams.
  • Squads: optionally list one player per line, shirt number first (for example 9 Saka). Typing a number straight after a code names its player.

Editing

Space plays and pauses. Arrows move one second (Shift for five). Comma and full stop nudge the chosen event by one frame. Delete removes the chosen event, Backspace removes the last one, and Ctrl+Z / Ctrl+Shift+Z undo and redo. Keys are ignored while you type in a field.

Your codes join the match feed's events in Filter and export. The Analyst Room keeps using the feed alone, so nothing is counted twice.

4. Filter and export

Filter turns the event list into clips. Use the controls on the left, press Find clips, then review, trim and export.

Quick presets

Four one-click starting points: Set pieces, Ball progression, Attacking chaos and Defensive display. They fill in the filters, which you can then adjust. Reset all clears everything.

The filter sections

SectionWhat it does
Team, players and periodPick a team (or both), specific players, and the half or periods to search.
Action typesChoose which kinds of event to find: passes, shots, tackles, carries and so on. The header shows how many are chosen.
QualifiersNarrow actions by detail, such as the outcome or how a shot was taken. The header shows how many qualifiers the match offers.
Pitch area and xTLimit events to a part of the pitch, and by expected-threat value.
Clip lengthSeconds before and after each event, and the merge gap: events closer together than this become one clip.
Timing correctionsFixes a recording that drifts from the match clock (see below).
Saved filtersSave the current setup under a name and recall it later, in any project.

Timing corrections

If part of the recording was cut or paused, every event after that point lines up wrongly. Choose the period, the match-clock time where it happens, what happened to the recording and how long, add an optional note, then press Add correction. Later events shift to match.

Review and trim

Press Find clips. The result appears as a timeline of clips with the player above it.

  • Click a clip to play it. Play on through every clip plays them back to back.
  • Trim with −1s / +1s on Start and End, or Set to playhead. You can also drag a clip's edges on the bar or timeline. Reset timing restores the original; Remove clip deletes it from the set.
  • Keys: Space play or pause, I and O set start and end, arrows seek one second or move to the previous or next clip.
  • Tick clips to select them. Select all and Select none help. The timeline's zoom slider helps with long lists.

Export

  1. Choose All clips or Selected, and One reel (a single video) or Separate files.
  2. Open File name, folder and quality to set the output folder (Browse), reel name, format (MP4) , quality and encoder.
  3. Press Export reel. Progress is shown and you can cancel at any time. When finished the file is in your chosen folder.

Annotate clip (or Annotate N clips) sends the clips to the Annotate screen instead of exporting directly.

5. Analyst Room

Charts built from the match's events. Seven tabs sit along the top; each has its own filters, and the numbers above a chart update as you change them. Use the Northbridge / Southport style team buttons to switch team.

TabWhat it shows
Shot MapEvery shot, sized by expected goals (xG), with outcome markers. Normal or Penalty Shootout mode; filter by player and pitch zone.
Pass MapA pass network: where players pass from, how often each link is used, passes, accuracy and key passes. Choose before or after substitutions and the minimum number of links.
Defensive ActionsTackles, interceptions, clearances, aerials, blocks, challenges and dispossessions, by player, pitch zone and depth zone.
Dribbles & CarriesPick a player to see their dribbles and carries on the pitch.
GoalkeeperPick a goalkeeper: their actions, shots faced and distribution.
Build-UpSequences of play: progressive chains, possession chains, final-third entries and box entries, with a minimum actions per sequence. Pick a sequence to inspect it.
PressingPressing wins by zone (all, high press in the final third, or mid-block), with press wins, high-press share and average press height.
ComparisonTwo players side by side: a performance radar and a shooting and xG breakdown.

Chart buttons

  • PNG: saves the chart as an image.
  • Send to clip: turns the plotted events into clips in Filter, so you can watch what you see.
  • Preview and GIF: an animated version of the chart (a style menu next to them picks the animation).

6. Tactical Lab

Team-level patterns. Open Match and team to choose the team. Tick Analyze across matches to combine every match in the project (see section 8).

TabWhat it shows
Defensive TransitionsWhat happens just after your team loses the ball: where losses happen and whether the opponent shot, entered the box or progressed. Sliders set the reaction window and the opponent event cap.
Attacking TransitionsThe same view after winning the ball: recovery locations, threat rate and progression rate, with sliders for the attack window and own event cap.
Style ProfileA radar of seven scores (possession control, pressing intensity, directness, wide play, final-third penetration, set-piece reliance and transition threat), with the figures behind each one explained underneath.
Set PiecesRestarts: how many, how often possession is kept, threat rate, and a map of where they are delivered.
Video LabRanks key moments from a chosen playlist, lets you add them to a reel and cut them as clips.

Video Lab reels

Choose a playlist and set how many seconds to keep before and after each moment. Tick moments to add them to the Reel (or press Add top 5), then cut them as clips. Highlighting a row also draws an event trace of what led up to it.

7. Annotate

Draw on your clips and build a finished analysis video. Open it with Annotate clip from Filter, or from the Annotate tab.

Tools

GroupTools
DrawArrow, Line, Freehand, Shape
HighlightZone, Spotlight (a cone on a player), Ring that tracks a player, numbered Token
PitchOffside line, Measure, Minimap
WriteText, with colour, background, size and bold

Most tools have a letter shortcut shown next to them. Click a tool, then click or drag on the video.

Add at this frame

  • Freeze frame: pauses the picture for a set time.
  • Board from frame: turns the frame into a tactics board with the players.
  • Insert picture: place a chart or a photo for a few seconds.
  • Mark the pitch: flat rings and arrows drawn on the pitch.

Timeline

The timeline shows tracks for Clips, Video, Inserts and Drawings. Each drawing is a bar you can drag to change when it appears. In Timing and animation set From and Until (press Here to use the playhead) and how it comes in and goes out. Follow a player makes a drawing follow a player through the clip. Split, Add clip, Card and the zoom buttons let you cut, add more clips, add a title card and zoom the timeline. The lists at the bottom (Parts, Freezes and boards, Drawings) let you select and remove items.

When you are happy, export the annotated video from the Annotate screen. It is saved to your chosen folder as a normal video file.

8. Projects, matches and your data

Several matches in one project

In Filter, the Matches button lists the matches in the project. Add another saved match with Add a saved match; each keeps its own events, footage and kick-off times, and the list shows whether video and kick-offs are set. Use the Match menu at the top to choose which match you are working on. In Analyst and Tactical, Analyze across matches combines them.

Where things are kept

  • Projects, events and settings are saved on your computer, automatically.
  • Footage is read from where it already is. If you move or rename a video, choose it again in Intake.
  • Exports go to the folder you set; nothing leaves your computer.
  • Starting a new project never erases the old one.
Back up by copying your exported videos and, if you want your projects safe, the VizorPlay data folder in your user profile.

9. Updating and keyboard tips

Updating

VizorPlay checks for a newer version and shows a notice in the app when one exists. Updates are signed and checked before they are applied. On Linux the app updates the .deb package through your system's package manager. If you installed with Homebrew on a Mac, you can update with Homebrew instead. Your projects are kept.

10. Troubleshooting

ProblemWhat to try
Status does not say Engine readyWait a few seconds after opening. If it stays, close and reopen the app. On a Mac, make sure you opened it as described on the download page.
A match link does not loadCheck the link opens in your browser and is a Scoresway or WhoScored match page. Otherwise import a CSV.
Clips show the wrong momentRe-check the kick-off markers in Intake for that period. If the recording was cut or paused, add a timing correction in Filter.
No clips foundLoosen the filters (press Reset all), or lower the number of qualifiers you chose.
Video will not play or is missingChoose the footage again in Intake. Use MP4, MKV or MOV.
Export is slow or failsPick a different output folder with free space, and try the default encoder. You can cancel an export and start again.
