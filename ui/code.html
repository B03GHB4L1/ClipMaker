Teams and keys

A code's letter makes an event at the playhead for the chosen team; an interval's letter starts it, and again stops it. H and A choose the team. Space plays and pauses; the arrows move 1 second (with Shift, 5). Comma and full stop nudge the chosen event by a frame (with Shift, a second). Delete removes the chosen event, Backspace the last one you made. Shift and a tag's letter tags the chosen event (or, with none chosen, the next one); a number typed after a code names its player. Ctrl+Z undoes, Ctrl+Shift+Z redoes. Keys do nothing while you type in a field.

Squads

Optional. One player per line, shirt number first ("9 Saka"). Type a number straight after a code, or with an event chosen, to name its player.

Code panel: Match: two teams

A panel is the set of codes and tags you code with. Templates are shared by all projects and import and export as JSON files. A project keeps its own copy, so changing a template later never touches its codes.

Clip lead-in and lead-out

Seconds each code's clip starts before and runs after the moment; an interval's clip runs from its start to its end. These replace Filter's clip length for coded events.
